# Sistema de Gestión de Espacios FAMEX

Aplicación web para consultar, reservar y administrar pabellones, chalets y espacios de exposición. 

## Funcionalidades

- Mapa general y navegación por pabellón.
- Planos interactivos con zoom, desplazamiento y filtros.
- Consulta de categorías, disponibilidad, empresas y contactos.
- Solicitudes públicas de reservación.
- Gestión de espacios, logotipos, ocupación y solicitudes.
- Editores visuales de áreas y recuadros.
- Administración de pabellones y usuarios.
- SQLite en desarrollo y MySQL en producción.



## Requisitos

- PHP 8.1 o posterior.
- Extensiones `PDO`, `fileinfo` y `gd`.
- Desarrollo: `pdo_sqlite` y `sqlite3`.
- Producción MySQL: `pdo_mysql`.
